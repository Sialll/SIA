# SIA 판매용 전환 체크리스트

기준일: 2026-03-11

이 문서는 현재 SIA를 `내부 운영형 프로토타입`에서 `개인 판매용 제품`으로 올리기 위해 필요한 미달 항목을 정리한 체크리스트다.

## 1. 현재 제품 판단

- 현재 상태: 실데이터 검증이 많이 진행된 판매 직전 수준의 내부 베타
- 아직 아닌 상태: 일반 개인 고객에게 바로 판매 가능한 완제품
- 핵심 제약:
  - 설치/패키징 흐름이 제품 수준이 아님
  - 사용자 화면이 아직 제품형 마감 전 단계임
  - 설치/업데이트/복구 흐름이 제품 수준이 아님

## 2. 출시 전 필수 조건

### A. 데이터/신호 품질

- [x] 미국장 기준 watchlist 장중 반영률 `100%` 확인
- [x] `mock 제외 + source 정합성` 기준 유지 상태에서 mock 비중 `0.00%` 정리
- [x] `data-quality-report.html` 판정 `양호` 확보
- [x] `backtest-readiness-report.html` 판정 `준비 완료` 확보
- [ ] `AAPL/MSFT` 외 `NVDA/AMZN/GOOGL/META/TSLA/ASTS/INTC` 장중 스냅샷이 더 충분히 쌓이는지 추적
- [ ] factor 결과가 일부 종목 편향인지 재점검
- [ ] 휴장일/장중/데이터 지연 상황에서 사용자에게 잘못된 확신을 주지 않는지 점검

### B. 사용자용 UX

- [ ] 사용자 화면을 `메인 / 종목 / 백테스트 / 설정` 수준으로 단순화
- [ ] 관리자 리포트는 사용자 메인에서 분리 유지
- [ ] 점수 의미, 감점 요인, 실시간/오프라인 차이를 한 번에 이해 가능하게 정리
- [ ] 티커 추가/삭제/일괄 설정 흐름을 일반 사용자 기준으로 점검
- [ ] 종목이 보이지 않을 때 이유를 명확히 표시
- [ ] 휴장 중에도 “마지막 저장 점수”를 신뢰성 있게 읽을 수 있도록 안내

### C. 설치/배포

- [ ] macOS용 배포 패키지 구조 정리
- [ ] Windows용 실행 패키지 구조 정리
- [ ] 첫 실행 설정 마법사 또는 단계형 초기 설정 제공
- [ ] 텔레그램 연결 테스트 흐름 단순화
- [ ] env/launchd/내부 스크립트 개념을 사용자에게 숨김
- [ ] 업데이트 경로 정의
- [ ] 실패 시 복구/초기화 흐름 정의

### D. 제품 운영

- [ ] 버전 표시
- [ ] 릴리스 노트 관리
- [ ] 오류 보고/로그 수집 정책 정의
- [ ] 라이선스/활성화 정책 정의
- [ ] 데이터 소스 장애 공지 기준 정의
- [ ] 사용자 문의 대응용 FAQ 초안 작성

## 3. 우선순위

### 1순위: 지금 바로 해야 하는 것

- 판매용 UI 마감
- 설치/패키징 흐름 정리
- signal quality가 일부 종목 편향이 아닌지 확인

### 2순위: 품질이 확보된 뒤 해야 하는 것

- 판매용 화면 구조 재설계
- 도움말/설명/점수 근거 강화
- 사용자 설정 흐름 단순화

### 3순위: 출시 직전 해야 하는 것

- 앱 패키징
- 업데이트/복구/버전 정책
- 라이선스/판매 운영 준비

## 4. 출시 판단 기준

아래 조건을 동시에 만족해야 `판매 시작 가능`으로 본다.

- [ ] 장중 현재 watchlist 반영률이 안정적으로 높음
- [ ] `mock 제외 + source 정합성` 기준에서 품질 리포트 해석 가능
- [ ] 사용자 화면만으로 핵심 사용 흐름 수행 가능
- [ ] 설치와 텔레그램 연결이 비개발자 기준으로 가능
- [ ] 도움말 없이도 점수 의미를 대체로 이해 가능
- [ ] 관리자용 정보와 사용자용 정보가 명확히 분리됨

## 5. 권장 작업 순서

1. watchlist 전 종목 신호 누적 확인
2. 판매용 IA/UI 마감
3. 도움말/설명/점수 근거 마무리
4. 설치/배포 구조 정리
5. 라이선스/업데이트/복구 체계 준비

## 6. 하지 말아야 할 것

- 데이터 품질 확보 전에 UI만 예쁘게 만드는 일
- readiness가 낮은데 수익률 숫자를 마케팅 문구처럼 사용하는 일
- 관리자용 진단 화면을 일반 사용자 메인에 그대로 노출하는 일
- 자동주문 기능을 다시 넣는 일
